# Changelog

## 0.1.3 — 2026-10-20

- Fix unreadable New Prompt, Save and Insert buttons in the DSH dark theme.
- Use the host's paired primary-button background and foreground colors.
- Check button contrast, hover states and form visibility in both themes.

## 0.1.2 — 2026-10-20

- Align the pinned prompt row with the composer using the host's width and side spacing.
- Keep pins aligned when resizing the window or using an embedded composer.
- Add a browser regression check for wide, narrow and host-defined layouts.

## 0.1.1 — 2026-10-20

- Verify compatibility with the Windows Desktop distribution's 0.2.0-rc.2 runtime.

## 0.1.0 — 2026-10-20

- Native DeepSeek Harness composer palette and four pinned prompt buttons.
- Editable starter prompts, search, categories and recent use.
- Global and workspace-scoped prompts.
- Variable fields, preview, and revision-guarded undoable draft insertion.
- Additive JSON import/export and explicit storage recovery.
- Chinese/English interface, themes, keyboard navigation and opt-in shortcut.
- Prebuilt client bundle, automated tests and CI.
